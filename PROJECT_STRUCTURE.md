## ? Validações Implementadas

### 1. Existência do Arquivo
```csharp
if (!File.Exists(filePath))
    throw new FileNotFoundException(...)
```

### 2. Extensão PNG
```csharp
if (!filePath.EndsWith(".png", StringComparison.OrdinalIgnoreCase))
    throw new ArgumentException(...)
```

### 3. Formato L16 (16-bit Grayscale)
```csharp
if (image is not Image<L16> image16Bit)
{
    if (image is Image<L8> image8Bit)
        throw new InvalidOperationException(
            "Use PNG 16-bit (grayscale)");
    // ...
}
```

### 4. Dimensões Mínimas
```csharp
if (width < 2 || height < 2)
    throw new InvalidOperationException(
        "Mínimo: 2x2 pixels");
```

### 5. Dimensões Máximas
```csharp
if (width > 4096 || height > 4096)
    throw new InvalidOperationException(
        "Máximo: 4096x4096");
```

### 6. Leitura Eficiente
```csharp
image.ProcessPixelRows(accessor =>
{
    for (int y = 0; y < height; y++)
    {
        Span<L16> pixelRow = accessor.GetRowSpan(y);
        for (int x = 0; x < width; x++)
        {
            ushort heightValue = pixelRow[x].PackedValue;
            heightmap.SetHeight(x, y, heightValue);
        }
    }
});
```

### Fluxo A: Gerar Teste
```
1. Click "Generate Test Terrain"
2. Terreno procedural 64x64 aparece
3. OK para testes rápidos
```

### Fluxo B: Importar Real
```
1. python3 generate_test_heightmap.py --size 512
2. Click "Import Heightmap (PNG 16-bit)"
3. Selecionar test_heightmap.png
4. Terreno 512x512 importado
5. Usar slider para ajustar escala
```

### Fluxo C: Dados Reais
```
1. GDAL converter: gdal_translate -of PNG -ot UInt16 srtm.tif output.png
2. Click "Import Heightmap (PNG 16-bit)"
3. Selecionar output.png
4. Visualizar terreno real em 3D
```
